# 菊池隆弘（個人ページ）

埼玉県朝霞市。建設業25年。会社の仕事をAIで組み替えてきた記録と、その途中で作った小さな道具の置き場。
売り物ではない。

**公開URL**: https://kohaku0521.github.io/app-yasan/

## 構成
- 入口: `index.html`
- 道具: `apps/*.html`（1本＝1ファイル。サーバー不要。記録は利用者の端末の中にだけ）
- 顔写真: `me.png`（無いときは自動で隠れる）
- 公開: `main` に push すると GitHub Actions が GitHub Pages へ出す（`.github/workflows/pages.yml`）

## 道具を足すとき
1. `apps/` に1ファイルのHTMLを置く
2. `index.html` の一覧に1行足す
3. `main` に push

## 決めていること
- 記録は利用者の端末の中にだけ。こちらのサーバーには何も送らない
- 薬・血圧・お金・法律の判断に使うものは作らない
- 広告は入れない。稼ぐ仕組みは入れていない
