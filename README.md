# つくったもの

解体業のかたわら、自分の会社の仕事をAIで組み替えてきた過程で作った小さな道具の置き場。売り物ではない。

2026-09-23: 「あなたのアプリ屋さん」という名前をやめた。店の名前は売る場所に見え、押し売りに読まれるため。

- 入口: `index.html`
- アプリ: `apps/*.html`（1本＝1ファイル。サーバー不要。記録は利用者の端末の中にだけ）
- 公開: `main` に push すると GitHub Actions が GitHub Pages へ出す（`.github/workflows/pages.yml`）

## アプリを足すとき

1. `apps/` に1ファイルのHTMLを置く
2. `index.html` の一覧に1行足す
3. `main` に push

## 約束

- 記録は利用者の端末の中にだけ。こちらのサーバーには何も送らない
- 薬・血圧・お金・法律の判断に使うものは作らない
- 広告は入れない。稼ぐ仕組みは入れていない
