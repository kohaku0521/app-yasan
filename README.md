# 菊池隆弘（個人ページ）

埼玉県朝霞市・建設業25年・47歳。会社の仕事をAIで組み替えてきた記録と、その途中で作った小さな道具の置き場。売り物ではない。

**「建設業」までは出す。「解体」は先頭に出さない**（2026-09-23 指示: 「解体屋はあとから出していきます」「建設業は出してもいい」）。
理由: 先頭に業種を置くと読み手がそこでカテゴリ分けしてしまい、いま書きたいこと（AIで会社を組み替えた記録）が入らない。信用が付いてから出す。

**顔写真**: リポジトリ直下に `me.jpg` を置くと、ページ上部に丸く表示される。無いときは自動で隠れる（`onerror`）。
GitHubの画面から「Add file → Upload files」で上げられる。

2026-09-23: 「あなたのアプリ屋さん」という名前をやめた。店の名前は売る場所に見え、押し売りに読まれるため。
2026-09-23: さらに、サービス名ではなく**本人を前面に**出す構成に変更。上から 名前と顔 → やってきたこと（数字） → つくったもの → 約束 → 連絡。

- 入口: `index.html`
- アプリ: `apps/*.html`（1本＝1ファイル。サーバー不要。記録は利用者の端末の中にだけ）
- 公開: `main` に push すると GitHub Actions が GitHub Pages へ出す（`.github/workflows/pages.yml`）

## アプリを足すとき

1. `apps/` に1ファイルのHTMLを置く
2. `index.html` の一覧に1行足す
3. `main` に push
